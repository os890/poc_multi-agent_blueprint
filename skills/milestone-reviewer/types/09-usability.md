# Usability review

Scope: The changed user-facing result (UI, messages, defaults, CLI output).

Check:

- A first-time user understands what to do; wording is clear and consistent with the rest of the product.
- Loading, empty and error states; destructive actions say exactly what happens and ask for confirmation.
- Keyboard operation and accessibility (focus, labels, contrast); the project's UI spec is followed.
- Large amounts (many items, long names, deep trees) stay practical.
